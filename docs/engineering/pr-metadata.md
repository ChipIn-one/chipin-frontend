# Frontend PR metadata

Contract (Task identity, routes, labels, owner and reviewer rules): [org `automation/pr-metadata.md`](https://github.com/ChipIn-one/.github/blob/master/automation/pr-metadata.md). This page lists only what is specific to the frontend.

- **Caller:** [`.github/workflows/pr-metadata.yml`](../../.github/workflows/pr-metadata.yml) calls the shared `pr-metadata-action`, pinned to an exact commit. It does not check out PR code.
- **Triggers:** `pull_request` to `master` from same-repo branches (opened, reopened, edited, synchronize, ready_for_review; Dependabot PRs are filtered out), completed `Frontend CI` `workflow_run` for same-repo PRs, and manual `workflow_dispatch` with the PR number and exact head SHA.
- **Credentials used by this workflow:** the job's scoped `GITHUB_TOKEN` for PR/Issue metadata and `CHIPIN_DEV_READ_TOKEN` for read-only canonical admission; no Project or Issue write credential. (The repository secret `CHIPIN_ISSUE_WRITE_TOKEN` is used only by `prepare-release-qa.yml`.)
- **PR bodies:** `npm run pr:create` ([`scripts/create-pr.mjs`](../../scripts/create-pr.mjs)) writes one `Task identity:` line and the `## Summary`, `## Tests`, `## Version impact`, `## Dependencies` headings; replace the prompts with verified evidence.
- **QA steps:** an implementation PR that changes UI-affecting paths (the list in [`scripts/release-qa/ui-paths.mjs`](../../scripts/release-qa/ui-paths.mjs), mirrored as `qaPolicy` in the org config) needs at least one QA step in its body: a `## QA (owner)` section with checklist steps, or `- [ ] QA: <step> => <expected>` lines. Without one the run fails with a `QA:` blocker; `None`/`n/a` does not count. The release QA Issue lists these steps ([release QA](release-qa.md)); rule and parse: [org `automation/pr-metadata.md`](https://github.com/ChipIn-one/.github/blob/master/automation/pr-metadata.md#qa-steps-for-ui-affecting-prs--268). Change `ui-paths.mjs` and the org `qaPolicy` together.
- **Review and merge:** the reconciler never approves or merges; independent review and human-only merges remain required.
