Production audit

The production dependency graph recorded in package-lock.json contains 144
package records: 138 MIT, 3 Apache-2.0, 2 ISC, and 1 0BSD. No GPL, LGPL,
AGPL, MPL, EPL, CDDL, SSPL, BUSL, custom, UNKNOWN, or UNLICENSED package was
reachable through the production dependency edges. The GPL/LGPL/MPL entries
in the lockfile are dev-only tooling dependencies and are not part of the
production dependency graph.

The 2026-08-30 production build included 83 package names in source maps.
The minified JavaScript did not preserve upstream license comments, so this
notice file should accompany any distributed production artifact. Re-run the
audit when production dependencies change.
